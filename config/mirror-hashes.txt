# s05 — Remix texture hashes of the GTA SA rear-view mirror textures.
#
# One hash per line: 0x + 16 hex digits. '#' starts a comment; the text after the hash is kept as a
# label and copied into the generated USD, so say which texture it is.
#
# Why these are needed: GTA SA *paints* its mirrors. The glass is a handful of triangles inside the
# car body atomic that sample the shared reflection stand-ins in models/generic/vehicle.txd. Under
# RTX Remix every surface is path traced, so those surfaces only need a perfectly smooth metallic
# material and Remix reflects what is behind them for free. Remix keys replacement materials to the
# texture hash of the texture the game uploaded (prim `mat_<HASH>`), and that hash is computed by
# the Remix runtime, not from the .txd bytes — so it has to be read out of the running game.
#
# How to read them (about 2 minutes, see docs/MIRRORS.md for the long version):
#   1. start the game with Remix, get into a car, look at a mirror (1st person or stand outside
#      and look at the door mirror);
#   2. open the RTX Remix developer menu (default Alt+X — `rtx.remixMenuKeyBinds`, unset here);
#   3. hover the crosshair over the mirror: the "Texture Info" popup shows "Hash: 0x…";
#      middle-click (or the "Copy Texture hash" button) copies it;
#   4. paste it below. Cross-check in the "Step 1: Categorize Textures" grid: the thumbnails and
#      sizes below are what you are looking for.
#
# Candidates from models/generic/vehicle.txd (measured, .strata/notes-s05-mirrors.md step 1):
#   xvehicleenv128    128x128, only 13 colours, hard 3-band gradient (brown / light blue-grey)
#                     -> the painted mirror glass itself. Start with this one.
#   vehicleenvmap128  128x128, 256 colours, smooth sky->ground gradient
#                     -> the fake environment reflection; add it if the first one is not enough.
# Do NOT add vehicleshatter128 (cracked-window overlay), vehiclegrunge256 (dirt), vehicletyres128,
# vehiclelights128/vehiclelightson128, vehiclesteering128, vehicledash32 or the plate textures.
#
# Leave everything commented out until you have real hashes: tools/mirrors.py refuses to generate
# an empty material file.
